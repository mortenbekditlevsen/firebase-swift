### 13.1.0
- [x] [fixed] Fixed callable streams failing with "Unexpected format for streamed response." when the server sends SSE comment lines, such as the `: ping` heartbeat emitted during long-running streaming functions. ([#16605](https://github.com/firebase/firebase-ios-sdk/pull/16605))

### 12.19.0
- [x] [changed] Requests directed to the local emulator over a non-loopback HTTP connection when tokens are present will now explicitly fail with an `unauthenticated` error instead of silently omitting the tokens and proceeding. ([#16536](https://github.com/firebase/firebase-ios-sdk/pull/16536))
  **Ported**; test `tokensAreNotSentOverHTTPToOtherHosts`.
- [x] [added] Added a DEBUG-only `allowInsecureTokenAttachment` property on `Functions` to allow insecure token attachment over HTTP for physical device testing. ([#16536](https://github.com/firebase/firebase-ios-sdk/pull/16536))
  **Ported**; test `insecureTokenAttachmentCanBeAllowedForDebugging`.

### 12.17.0
- [x] [fixed] Resolved a concurrency resource leak in Functions stream cancellation. ([#16392](https://github.com/firebase/firebase-ios-sdk/pull/16392))
  **Ported**: both streams cancel their task on termination.
- [x] [changed] Enforced stricter transport layer security when using the emulator: Auth, FCM, and AppCheck tokens are no longer attached to outbound requests if the connection is made over HTTP to a non-loopback host. ([#16395](https://github.com/firebase/firebase-ios-sdk/pull/16395))
  **Ported** (with the 12.19.0 change above).
