## CHANGELOG (`CHANGELOG.md`)

### 12.1.0
- [x] [added] Added `AppCheckCoreDebugProvider(serviceName:resourceName:baseURL:apiKey:requestHooks:debugToken:)`, which accepts a caller-provided debug token. The provided token is used when no debug token environment variable is set and takes priority over a previously stored or newly generated local debug token. Like environment variable tokens, exchanges using the provided token don't change the local token's registered state. ([#134](https://github.com/google/app-check/pull/134))
  **Ported** (upstream's diff, with the port's changes to `AppCheckCoreDebugProvider` applied again: internal API, `UserDefaults`).
- [x] [added] Added `AppCheckCoreDebugProvider.debugTokenSource` (`GACAppCheckDebugTokenSource`), which reports whether the current debug token came from an environment variable, the caller-provided token, or local storage. More sources may be added later; Swift `switch` statements over `AppCheckCoreDebugTokenSource` should include `@unknown default`. ([#134](https://github.com/google/app-check/pull/134))
  **Ported**; internal, like the rest of the vendored API.
- [x] [fixed] Fixed an issue where a cached token fetched while the device clock was ahead kept being served after the clock was corrected, because its stored dates inherited the offset. Cached tokens received in the future are now refreshed. (https://github.com/firebase/firebase-ios-sdk/issues/16939)
  **Ported**; upstream's test in `AppCheckCoreTests`.
- [x] [fixed] Fixed an issue where a debug token exchange using the `AppCheckDebugToken` or `FIRAAppCheckDebugToken` environment variable updated the locally generated debug token's registered state, which could suppress or repeat its registration instructions. ([#135](https://github.com/google/app-check/pull/135))
  **Ported**; upstream's tests in `AppCheckCoreDebugProviderTests`.
- [x] [fixed] Fixed an issue where provider request backoff could block retries if the device clock moved backward after a failed request. ([#137](https://github.com/google/app-check/pull/137))
  **Ported**; upstream's tests in `AppCheckCoreBackoffWrapperTests`.
