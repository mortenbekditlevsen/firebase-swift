### 13.0.0
- [x] [changed] Dropped C++14 support; Firestore now requires C++17.
  **Ported**: `cxxLanguageStandard: .gnucxx17`.
- [x] [changed] Update gRPC dependency to 1.83.1.
  **Ported**: grpc-ios 1.83.1, which builds on Linux unchanged.
- [x] [changed] Update Abseil dependency to 1.20250512.2.
  **Ported**: abseil-cpp-SwiftPM 0.20250512.1. Linux needs the `int128.h` fix again (Docs/UpstreamPatches.md).
- [x] [changed] Prefixed internal Pipeline Objective-C bridge classes and `NS_SWIFT_NAME` annotations with `__` to hide them from IDE autocomplete and prevent them from appearing alongside public APIs.
  **Ported**: the Swift bridge's stub classes have the `__` names.
- [x] [feature] Adds support for the following new types: `MinKey`, `MaxKey`, `RegexValue`, `Int32Value`, `Decimal128Value`, `BSONObjectId`, `BSONTimestamp`, and `BSONBinaryData`. ([#16265](https://github.com/firebase/firebase-ios-sdk/pull/16265))
  **Partly ported**: the C++ core has them. The Swift API doesn't yet (its `Codable` files are excluded in Package.swift), so documents return these values as their maps, and `Int32Value` as an integer. Bridging them is M3b work.
- [ ] [changed] Added the `Firestore` package trait to `Package.swift`. Cloud Firestore support now requires the trait to be enabled (it is enabled by default). Developers can opt out of the trait to avoid downloading Firestore's underlying dependencies (such as gRPC and Abseil). ([#16684](https://github.com/firebase/firebase-ios-sdk/pull/16684))
  **Not ported**: Firestore is a separate product here already. A trait would also let users skip fetching gRPC and abseil; worth adding.
