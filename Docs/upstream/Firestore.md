### CHANGELOG (`Firestore/CHANGELOG.md`)

#### 13.1.1
- [x] [fixed] Security Update: Removed compromised eMudhra intermediate CA root certificates from embedded trust store. ([#16930](https://github.com/firebase/firebase-ios-sdk/pull/16930))
  **Ported** (the regenerated `grpc_root_certificates_generated.cc`).

#### 13.1.0
- [x] [feature] Added support for Pipeline DML stages (`delete`, `update`, `insert`, `upsert`), `literals` source stage, and `Pipeline.ExecuteOptions(isAtomic:)`. ([#16859](https://github.com/firebase/firebase-ios-sdk/pull/16859))
  **Ported** at the API level: the Swift stages came with the patch, and the bridge has stubs for them. Pipelines don't execute in this port yet (M3b).

#### 13.0.0
- [x] [changed] Dropped C++14 support; Firestore now requires C++17.
  **Ported**: `cxxLanguageStandard: .gnucxx17`.
- [x] [changed] Update gRPC dependency to 1.83.1.
  **Ported**: grpc-ios 1.83.1, which builds on Linux unchanged.
- [x] [changed] Update Abseil dependency to 1.20250512.2.
  **Ported**: abseil-cpp-SwiftPM 0.20250512.1. Linux needs the `int128.h` fix again (Docs/UpstreamPatches.md).
- [x] [changed] Prefixed internal Pipeline Objective-C bridge classes and `NS_SWIFT_NAME` annotations with `__` to hide them from IDE autocomplete and prevent them from appearing alongside public APIs.
  **Ported**: the Swift bridge's stub classes have the `__` names.
- [x] [feature] Adds support for the following new types: `MinKey`, `MaxKey`, `RegexValue`, `Int32Value`, `Decimal128Value`, `BSONObjectId`, `BSONTimestamp`, and `BSONBinaryData`. ([#16265](https://github.com/firebase/firebase-ios-sdk/pull/16265))
  **Partly ported**: the C++ core has them. The Swift API doesn't yet (its `Codable` files are excluded in Package.swift), so documents return these values as their maps, and `Int32Value` as an integer. Bridging them is M3b work.
- [x] [changed] Added the `Firestore` package trait to `Package.swift`. Cloud Firestore support now requires the trait to be enabled (it is enabled by default). Developers can opt out of the trait to avoid downloading Firestore's underlying dependencies (such as gRPC and Abseil). ([#16684](https://github.com/firebase/firebase-ios-sdk/pull/16684))
  **Ported**: a default-enabled `Firestore` trait; nanopb, abseil and gRPC are conditional on it. A consumer with `traits: []` doesn't fetch them.
