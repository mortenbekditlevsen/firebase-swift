### 13.1.0
- [ ] [fixed] Fixed a race where calling childByAutoId() concurrently from multiple threads could generate duplicate push IDs. ([#16768](https://github.com/firebase/firebase-ios-sdk/pull/16768))
- [ ] [fixed] Fixed an issue where transactions could fail with a maxretry error when every child of a node had a priority. ([#16769](https://github.com/firebase/firebase-ios-sdk/pull/16769))
- [ ] [fixed] Fixed an issue where observers could miss events, and keep showing stale or reverted values, when multiple pending transactions at overlapping locations were rerun. ([#16791](https://github.com/firebase/firebase-ios-sdk/pull/16791))
- [ ] [fixed] Fixed an issue where a `getData` call that failed without a cached value kept its query marked as active in the persistence cache until the app restarted, which kept that location from being pruned. ([#16792](https://github.com/firebase/firebase-ios-sdk/pull/16792))
- [ ] [fixed] Fixed a potential crash at every launch after the server sent an invalid database host. Such hosts are now ignored, and a saved one is discarded. ([#16863](https://github.com/firebase/firebase-ios-sdk/pull/16863))
- [ ] [fixed] Fixed a potential crash when the server sent a data message with an `error`. ([#16863](https://github.com/firebase/firebase-ios-sdk/pull/16863))
- [ ] [fixed] Fixed a crash in `purgeOutstandingWrites` when the server had already acknowledged a write that the SDK hadn't processed yet. ([#5161](https://github.com/firebase/firebase-ios-sdk/pull/5161))
- [ ] [fixed] Fixed a crash in `getData` when the server returned an error without a reason. ([#16718](https://github.com/firebase/firebase-ios-sdk/pull/16718))
- [ ] [fixed] Ignore malformed realtime server push, control, and handshake messages instead of crashing when a frame or one of its fields has an unexpected JSON type. ([#16750](https://github.com/firebase/firebase-ios-sdk/pull/16750))
